# 单文件计算器 GitHub Pages 发布设计

## 背景

当前江苏电力曲线计算器位于 `zysd`，使用 React、TypeScript 和 Vite 构建。GitHub Pages 发布依赖自定义 Actions 工作流和构建产物，排障链路较长。用户已确认不再要求新的发布方案兼顾仓库中的旧 HTML 页面，只要求计算器能够以最简单的方式通过 GitHub Pages 发布，并接受 `github.io` 在中国大陆不保证稳定可达这一限制。

## 目标

- 将计算器发布版本实现为一个自包含的仓库根目录 `index.html`。
- 保留现有界面、响应式布局、默认数据、实时计算和恢复默认值功能。
- 页面运行不依赖 React、Vite、pnpm、Node.js、外部 CDN 或后端服务。
- GitHub Pages 使用 `main` 分支根目录作为发布源。
- 用户继续手动执行 `git push`；本地工作不执行 push。

## 非目标

- 不修改、迁移或验证 `anfeng`、`liubao` 等旧 HTML 页面。
- 不保证 `github.io` 在中国大陆所有网络环境中始终可访问。
- 不引入用户系统、数据库、服务器端计算或第三方 API。
- 不删除现有 `zysd` React 源码；它作为历史实现保留，避免不可逆迁移。

## 页面结构

仓库根目录新增 `index.html`，包含三部分：

1. 内嵌 CSS：复用当前蓝白配色、卡片布局、24 时点输入网格和移动端响应式样式。
2. 语义化 HTML：标题、两个结果卡片、两组各 24 个负荷输入框和恢复默认值按钮。
3. 内嵌 JavaScript：保存固定价格曲线、全省负荷、默认客户负荷以及加权均价算法。

页面加载时由 JavaScript 生成 48 个输入框、填充默认值并计算结果。任何输入变化都会立即重新计算。所有负荷之和为 0 或输入无效时，结果显示 `--`，不会抛出页面错误。

## 计算一致性

单文件版本沿用现有算法：

- 2026 曲线优势 = 2026 全省加权均价 - 2026 客户加权均价。
- 2027 市场价格曲线 = 2026 市场价格曲线 + 对应时点的 2027 调整值。
- 2027 曲线优势 = 2027 全省加权均价 - 2027 客户加权均价。
- 加权均价按每个时点负荷占总负荷的比例计算。
- 非有限输入按 0 处理，结果保留两位小数并使用中文数字格式。

现有 React 实现作为计算结果的对照基准。迁移测试必须证明默认数据和代表性修改数据在两种实现中的结果一致。

## GitHub Pages 发布方式

GitHub Pages 改为从 `main` 分支的仓库根目录发布：

- 发布入口：仓库根目录 `index.html`。
- 访问地址：`https://marvinfight.github.io/`。
- 不再使用自定义 GitHub Pages 构建与部署工作流。
- 删除 `.github/workflows/deploy.yml`，避免分支发布与自定义 Actions 同时部署产生竞争。

该方式仍会由 GitHub 内部完成 Pages 发布，但仓库自身不需要安装依赖或运行前端构建命令。

## 验证

实施完成后进行以下验证：

1. 静态检查：根目录 `index.html` 不引用本地源码、外部脚本、外部样式或 `/zysd/assets`。
2. 计算测试：默认值、单项修改、全零负荷和恢复默认值均符合现有算法。
3. 浏览器测试：在桌面和窄屏尺寸下检查输入、实时结果和按钮交互。
4. Git 检查：只提交单文件站点、相关测试和工作流移除；旧 HTML 文件无变化。
5. 用户手动 push 后，将 Pages Source 设置为 `Deploy from a branch`、`main`、`/(root)`，等待发布完成后访问根地址。

## 回退

现有 `zysd` 源码保留。如果单文件方案需要回退，可以恢复自定义 Pages 工作流并重新部署 `zysd` 构建产物；旧页面文件不参与本次改动。
