# 江苏电力曲线计算器

这是一个基于 Vite 和 React 的静态站点。

## 本地运行

在 `zysd` 目录中执行：

```powershell
pnpm install
pnpm dev
```

## 构建

```powershell
pnpm build
```

## GitHub Pages 部署

在 GitHub 仓库的 **Settings > Pages** 中，将部署源选择为 **GitHub Actions**。推送到 `main` 分支后，工作流会构建并发布 `dist` 目录；也可以在 Actions 页面手动触发工作流。

发布地址为：https://marvinfight.github.io/zysd/
